# **1\. OBJETIVOS**

## **Descrição do site**

A **Aureon Motors** é um site especializado na venda de carros de luxo de diversas marcas. A plataforma reunirá veículos esportivos, sedãs, SUVs e modelos exclusivos, apresentando imagens, preços, características e informações detalhadas de cada automóvel em uma interface moderna, elegante e fácil de utilizar.

## **Diferencial**

O principal diferencial da Aureon Motors será a **experiência de compra personalizada**. Além de pesquisar os veículos disponíveis, o cliente poderá encontrar modelos de acordo com seu estilo de vida, preferências e necessidades.

O site também apresentará:

* comparação entre veículos;  
* imagens detalhadas dos carros;  
* informações sobre desempenho, conforto e tecnologia;  
* veículos selecionados e verificados;  
* atendimento personalizado para ajudar na escolha;  
* possibilidade de solicitar uma visita ou test-drive.

Dessa forma, o site não funcionará apenas como uma vitrine, mas como uma **consultoria digital para a escolha de carros de luxo**.

## **Objetivo geral**

O objetivo da Aureon Motors é facilitar a pesquisa e a compra de carros de luxo, reunindo veículos de diferentes marcas em uma única plataforma. O site busca oferecer uma experiência segura, sofisticada e intuitiva, ajudando o cliente a comparar opções e encontrar o automóvel mais adequado ao seu perfil.

## **Público-alvo**

O público-alvo é formado por pessoas interessadas em carros de alto padrão, especialmente:

* empresários e profissionais com alto poder aquisitivo;  
* colecionadores e entusiastas de automóveis;  
* pessoas que procuram conforto, exclusividade e desempenho;  
* clientes interessados em veículos esportivos, sedãs e SUVs de luxo;  
* compradores que valorizam atendimento personalizado e segurança na negociação.

# **2\. DESIGN**

## Identidade visual

A identidade visual utiliza a regra 60-30-10 para criar equilíbrio e hierarquia. A cor dominante ocupa aproximadamente 60% da interface, a secundária organiza 30% das áreas de apoio e a cor de destaque aparece em 10% dos botões e elementos de ação.

| Proporção | Aplicação | Cor | Código |
| :---- | :---- | :---- | :---- |
| 60% | Fundo principal | Preto/cinza muito escuro | \#212121 |
| 30% | Áreas secundárias | Cinza escuro | \#2F2F2F |
| 10% | Destaques, botões e ações | Vermelho escuro | \#8A0000 |

## Tipografia

Archivo Black será utilizada nos títulos por seu estilo simples, marcante e moderno. Inter será utilizada no corpo do texto por sua clareza, legibilidade e aparência limpa.

## UX e estrutura semântica

O design em blocos organiza a página em cabeçalho, navegação, conteúdo principal, seções e rodapé. No código, essa organização será representada por elementos semânticos como header, nav, main, section e footer. Planejar essa estrutura antes do CSS facilita o desenvolvimento, melhora a manutenção, a acessibilidade e a experiência do usuário.

## Wireframe melhorado

O novo wireframe preserva as três páginas obrigatórias, mas aprimora a hierarquia visual, a navegação, os filtros, os cards de veículos e o formulário de contato.

## Simulação de alta fidelidade

A simulação apresenta como o site poderá ficar depois da aplicação das imagens, da tipografia e da paleta 60-30-10.

# **3\. DESENVOLVIMENTO**

## Páginas planejadas

Home: apresentação da marca, banner principal, modelos em destaque, diferenciais e rodapé.

Veículos: catálogo com filtros, comparação, informações resumidas e acesso aos detalhes.

Contato: informações de atendimento e formulário para contato, visita ou test-drive.

## Requisitos funcionais

| Código | Requisito |
| ----- | ----- |
| RF01 | O site deve exibir os carros disponíveis para venda. |
| RF02 | O usuário deve poder visualizar imagens, preço, marca, modelo e características de cada veículo. |
| RF03 | O usuário deve poder pesquisar veículos pelo nome ou pela marca. |
| RF04 | O site deve permitir filtrar os veículos por marca, preço ou categoria. |
| RF05 | O usuário deve poder comparar as características de diferentes veículos. |
| RF06 | O site deve apresentar uma página de contato com formulário. |
| RF07 | O usuário deve poder solicitar atendimento, visita ou test-drive. |
| RF08 | O menu deve permitir a navegação entre as páginas Home, Veículos e Contato.  |

## Requisitos não funcionais

| Código | Requisito |
| :---- | :---- |
| RNF01 | O site deve possuir uma interface simples, elegante e intuitiva. |
| RNF02 | O design deve seguir as cores \#212121, \#2F2F2F e \#8A0000. |
| RNF03 | O site deve ser responsivo e funcionar em computadores, tablets e celulares. |
| RNF04 | As páginas e imagens devem carregar rapidamente. |
| RNF05 | Os textos, botões e informações devem ser legíveis e possuir bom contraste. |
| RNF06 | O site deve funcionar nos navegadores mais utilizados. |
| RNF07 | A navegação e a identidade visual devem ser consistentes em todas as páginas. |

## Infraestrutura

O projeto será desenvolvido em um computador ou notebook e testado também em celulares para verificar a responsividade. Será necessária conexão com a internet para acessar o Figma, GitHub e ferramentas de apoio.

## Hospedagem

O site será hospedado gratuitamente no GitHub Pages, pois será desenvolvido inicialmente com HTML, CSS e JavaScript. A plataforma também facilita a publicação das atualizações enviadas ao GitHub.
